How ReBAC Works

CacheSplit uses Relationship-Based Access Control backed by a live SQLite edge graph.

Clinician
  ASSIGNED_TO → Visit
    ← HAS_CURRENT_VISIT ← Patient
    CONTAINS_LAB → LabResult
    ALLOCATED_BED → Bed

BFS traversal up to depth 4 over rebac_edges table. Only clinicians with an active ASSIGNED_TO path can access patient data.
